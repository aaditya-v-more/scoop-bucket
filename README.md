# scoop-bucket

Scoop manifests for my Windows tools.

```
scoop bucket add aaditya https://github.com/aaditya-v-more/scoop-bucket
scoop install google-tts-local
```

| App | Description |
| --- | --- |
| [google-tts-local](https://github.com/aaditya-v-more/google-tts-local) | Google's on-device text-to-speech voices, run locally with a command line and an HTTP server |
